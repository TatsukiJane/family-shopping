# Семейный список покупок

Общий список «что закончилось» для семьи. Любой добавляет позицию, любой
отмечает купленное — все видят актуальное состояние. Работает оффлайн,
ставится на домашний экран, бэкенда нет: данные лежат одним JSON-файлом
в вашем приватном GitHub-репозитории.

## Как это работает

- **Данные** — `data/list.json` в приватном репозитории, через GitHub Contents API.
  Версионирование и откат к любому состоянию — из истории коммитов.
- **Оффлайн** — список читается из локальной копии, отметки применяются сразу
  и уезжают, когда появится сеть. Индикатор честно показывает, сколько
  изменений ещё ждут.
- **Конфликты** — если двое отметили позиции одновременно, сохраняются обе
  отметки.
- **Участники** — подписывают действия: видно, кто добавил позицию и кто её
  купил. Пароля нет: доступ к списку даёт токен, а он лежит на вашем телефоне.

## Установка

1. Создайте **приватный** репозиторий для данных — пустой, файл приложение
   создаст само.
2. Форкните или скопируйте этот репозиторий, в его настройках включите
   **Pages → Source: GitHub Actions**.
3. Там же, в **Settings → Secrets and variables → Actions → Variables**,
   добавьте:
   - `VITE_DATA_OWNER` — ваш логин на GitHub,
   - `VITE_DATA_REPO` — имя приватного репозитория с данными,
   - `VITE_DATA_BRANCH` — ветка, если она не `main`,
   - `VITE_DATA_PATH` — путь к файлу, если он не `data/list.json`.

   Переменные читаются на сборке, поэтому задайте их до первого пуша — иначе
   приложение соберётся с пустыми координатами репозитория.
4. Выпустите fine-grained PAT
   ([Settings → Developer settings](https://github.com/settings/personal-access-tokens)):
   доступ — только репозиторий с данными, разрешение — **Contents: Read and write**.
5. Запушьте в `main`. Actions соберёт и опубликует сайт.
6. Откройте ссылку на телефоне, введите токен, назовите себя и добавьте иконку
   на домашний экран.

Остальные члены семьи открывают ту же ссылку, вводят тот же токен и выбирают
себя из списка либо добавляются новым участником.

> Токен хранится только в браузере устройства. Не размещайте в этом списке
> ничего чувствительнее «купить творог» — подробности в [CLAUDE.md](CLAUDE.md).
